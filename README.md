## 用途

本项目是「大气污染扩散反演与溯源平台」的代码仓库，用于该方向的建模与数据处理，目前已提供高斯烟羽扩散、情景健康影响评估与风险聚合等算法。

## 环境与安装

- Python 3.11 及以上

```bash
python -m pip install -e .
```

## 测试

```bash
python -m pytest
```

当前尚无测试用例，收集到 0 个用例属预期结果。

## 现有公开接口

- 命令行程序 `air-quality-modeling`
- Python 包 `air_quality`，其 `__version__` 为当前版本号
- 包根公开函数：`persistence`、`forecast`、`forecast_interval`、`aggregate`
- 健康影响评估模块 `air_quality.health`（通过 `air_quality.health.xxx` 调用，不在包根导出），提供以下函数：
  - `assess(C, U, P, beta, baseline=0)`：评估各情景相对基线情景的健康影响，返回 `(H, S, W, Q)`
  - `aggregate(H, W, weights=None, z=1.96)`：跨情景聚合各受体健康影响及区间，返回 `(M, R, lower, upper, total, total_spread)`
  - `aggregate_correlated(H, F, weights=None, z=1.96)`：考虑受体误差相关时的跨情景聚合
  - `any_receptor_probability(H, W, thresholds, weights=None)`：假定同一情景内各受体误差独立时，至少一个受体超过各级阈值的跨情景加权概率，返回阈值序的 3 长 `list[float]`
  - `at_least_count_probability(H, W, thresholds, min_count=1, weights=None)`：假定同一情景内各受体误差独立时，至少 `min_count` 个受体超过各级阈值的跨情景加权概率；`min_count` 为非 bool 且 `>=1` 的 int（`>N` 时概率为 0），返回阈值序的 3 长 `list[float]`，不舍入
  - `exceedance_probability(H, W, thresholds)`：各情景总影响超过各级阈值的概率
  - `risk_probability(H, W, thresholds, weights=None)`：跨情景加权聚合的超标风险概率
  - `risk_interval(H, W, thresholds, weights=None, z=1.96)`：跨情景聚合影响区间与超标风险
  - `risk_excess_quantile(H, W, thresholds, quantiles, weights=None)`：总影响阈值期望超额的跨情景加权分位数。`H`、`W` 为同形 K×N（K,N>0）list/tuple 矩阵，元素为非 bool 有限 int/float（`H` 可负，`W` 元素 ≥0）；`thresholds` 恰为 3 个严格递增的非 bool 有限非负数；`quantiles` 为非空 list/tuple，元素为非 bool 有限数且 `0≤q<1`、非递减；`weights` 为 `None`（取等权 `1/K`）或 K 长 list/tuple，元素为非 bool 有限非负数且 `fsum>0`（按 `fsum` 归一）。容器/元素类型错抛 `TypeError`；空、空行、锯齿、形状/长度不符、非有限、负值、阈值/分位越界或递减、权和 ≤0 抛 `ValueError`。令 `μk=fsum(H[k])`、`σk=hypot(*W[k])`、`t=thresholds[j]`：`σk>0` 时 `a=(t−μk)/σk`、`e=σk*exp(−a²/2)/sqrt(2π)+(μk−t)*erfc(a/sqrt(2))/2`；`σk=0` 时 `e=max(μk−t,0)`。对每个阈值 `j` 将各情景按 `(e[k][j],k)` 升序排列，分位 `q=0` 取首项，否则取累计归一权首次 `>=q` 的情景。返回分位×阈值序 M×3 `list[list[float]]`，不舍入
  - `level_probability(H, W, thresholds, weights=None)`：跨情景加权聚合的健康等级概率
  - `receptor_level_probability(H, W, thresholds)`：分受体的健康等级概率
  - `receptor_level_path_probability(H, W, thresholds, paths)`：给定逐情景健康等级路径在各受体处的发生概率（情景误差独立）。`H`、`W` 为同形 K×N（K,N>0）list/tuple 矩阵，外层/行限 list/tuple 且等宽；`H` 元素为非 bool 有限 int/float（可负），`W` 元素为非 bool 有限 int/float 且 ≥0；`thresholds` 为 list/tuple，恰含 3 个严格递增非 bool 有限非负数；`paths` 为非空 list/tuple，`paths[m]` 为长度 K 的 list/tuple，元素为非 bool int 且 `0≤level≤3`。容器、行或元素类型错抛 `TypeError`；空、空行、锯齿、形状/长度不符、非有限、W 负、thresholds 长度/顺序/负值非法或 level 越界抛 `ValueError`。令 `μ=H[k][i]`、`σ=W[k][i]`：`σ>0` 时 `qj=erfc((thresholds[j]−μ)/(σ*sqrt(2)))/2`，否则 `thresholds[j]≤μ` 取 `1.0`、否则 `0.0`；`p[k][i]=[1−q0, q0−q1, q1−q2, q2]`。按 `m`、`i` 序以 `math.prod(p[k][i][paths[m][k]] for k in 0..K−1)` 求概率。返回 M×N（`M=len(paths)`）的 `list[list[float]]`，按路径/受体序，不舍入
  - `receptor_level_interval(H, W, thresholds, weights=None, z=1.96)`：分受体期望健康等级的跨情景加权均值与区间。`H`、`W` 为同形 K×N（K,N>0）list/tuple 矩阵，元素为非 bool 有限数（`H` 可负，`W` 非负）；`thresholds` 恰为 3 个严格递增的非 bool 有限非负数；`weights` 为 `None`（取等权 `1/K`）或 K 个非负有限权且 `fsum>0`（按 `fsum` 归一）；`z` 为非负有限数。容器/元素类型错抛 `TypeError`；空、锯齿、形状/长度不符、非有限、负值、阈值顺序、权和或 `z` 非法抛 `ValueError`。对 `μ=H[k][i]`、`σ=W[k][i]`：`σ>0` 时 `qj=erfc((Tj−μ)/(σ*sqrt(2)))/2`，否则 `Tj≤μ` 取 `1.0`、否则 `0.0`；`p=[1−q0, q0−q1, q1−q2, q2]`，`e[k][i]=fsum(r*p[r] for r in 0..3)`、`v[k][i]=fsum(r²*p[r] for r in 0..3)−e[k][i]²`。`M[i]=fsum(w[k]*e[k][i])`、`V[i]=fsum(w[k]*((e[k][i]−M[i])²+v[k][i]))`、`R=z*sqrt(V)`、`L=M−R`、`U=M+R`，返回受体序 4 项 N 长 `list[float]` 的 `(mean, spread, lower, upper)`，均不舍入
  - `receptor_level_quantile(H, W, thresholds, quantiles, weights=None)`：分受体健康等级的跨情景加权分位数。`H`、`W` 为同形 K×N 矩阵（`H` 元素可负，`W` 元素非负）；`thresholds` 为 3 个严格递增非负数；`quantiles` 为非空、`[0,1]` 内非递减序列；`weights` 为 `None`（取等权 `1/K`）或按 `fsum` 归一的 K 个非负权。对 `σ=W[k][i]`：`σ>0` 时 `qj=erfc((thresholds[j]−H[k][i])/(σ*sqrt(2)))/2`，否则 `qj=1.0`（`thresholds[j]≤H[k][i]`）或 `0.0`；`p[k][i]=[1−q0, q0−q1, q1−q2, q2]`，`P[i][r]=fsum(w[k]*p[k][i][r])`；分位 `q=0` 取 `0`，否则取最小等级 `r` 使 `fsum(P[i][s] for s in 0..r)>=q`。返回分位×受体序的 M×N `list[list[int]]`
  - `receptor_level_rise_distribution(H, W, thresholds)`：各受体在逐情景序列中健康等级上升次数的分布（情景误差独立，按给定情景次序折入，「上升」指相邻两情景由较低等级进入严格更高等级）。`H`、`W` 为同形 K×N（K≥2,N>0）list/tuple 矩阵，外层/行限 list/tuple 且等宽；`H` 元素为非 bool 有限 int/float（可负），`W` 元素为非 bool 有限 int/float 且 ≥0；`thresholds` 为 list/tuple，恰含 3 个严格递增非 bool 有限非负数。类型错抛 `TypeError`；空、空行、锯齿、K<2、形状不符、非有限、W 负、thresholds 长度/顺序/负值非法抛 `ValueError`。令 `μ=H[k][i]`、`σ=W[k][i]`、`Tj=thresholds[j]`：`σ>0` 时 `qj=erfc((Tj−μ)/(σ*sqrt(2)))/2`，否则 `Tj≤μ` 取 `1.0`、否则 `0.0`；`p=[1−q0, q0−q1, q1−q2, q2]`。每受体 `i` 令 `D[r][0]=p[0][i][r]`、其余为 0；对 `k=1..K−1`、`c=0..k` 按 `D′[b][c]=fsum(D[a][c−(a<b)]*p[k][i][b] for a in 0..3)` 更新（越界项略去）。返回 `R[i][c]=fsum(D[r][c] for r in 0..3)`，为受体×上升次数（`c=0..K−1`）序的 N×K `list[list[float]]`，不舍入
  - `receptor_level_run_distribution(H, W, thresholds)`：各受体各健康等级在逐情景序列中的最长连续长度（run）分布（情景误差独立，按给定情景次序折入，每受体、每等级独立递推）。`H`、`W` 为同形 K×N（K,N>0）list/tuple 矩阵，外层/行限 list/tuple 且等宽；`H` 元素为非 bool 有限 int/float（可负），`W` 元素为非 bool 有限 int/float 且 ≥0；`thresholds` 为 list/tuple，恰含 3 个严格递增非 bool 有限非负数。容器/元素类型错抛 `TypeError`；空、空行、锯齿、形状不符、非有限、W 负、thresholds 长度/顺序/负值非法抛 `ValueError`。令 `μ=H[k][i]`、`σ=W[k][i]`、`Tj=thresholds[j]`：`σ>0` 时 `qj=erfc((Tj−μ)/(σ*sqrt(2)))/2`，否则 `Tj≤μ` 取 `1.0`、否则 `0.0`；`p=[1−q0, q0−q1, q1−q2, q2]`。对每受体 `i`、等级 `l` 在状态 `(r,m)`（当前连续长度 `r`、历史最长 `m`）上递推，初态 `D[(0,0)]=1.0`；按 `k=0..K−1`、状态键字典序，`l` 事件以 `p[k][i][l]` 转 `(min(r+1,K), max(m,r+1))`，非 `l` 事件以 `1−p[k][i][l]` 转 `(0,m)`，落入同一目标状态的概率以 `math.fsum` 合并；终态按最长值 `m` 以 `math.fsum` 汇总。返回 `R[i][l][m]` 为受体×等级×最长长度（`m=0..K`）序的 N×4×(K+1) `list[list[list[float]]]`，不舍入
  - `receptor_level_run_quantile(H, W, thresholds, quantiles)`：各受体各健康等级在逐情景序列中最长连续长度（run）的分位数（情景误差独立，按给定情景次序折入，每受体、每等级独立递推）。`H`、`W` 为同形 K×N（K,N>0）list/tuple 矩阵，外层/行限 list/tuple 且等宽；`H` 元素为非 bool 有限 int/float（可负），`W` 元素为非 bool 有限 int/float 且 ≥0；`thresholds` 为 list/tuple，恰含 3 个严格递增非 bool 有限非负数；`quantiles` 为非空 list/tuple，元素为非 bool 有限数、`0≤q<1` 且非递减。容器/元素类型错抛 `TypeError`；空、空行、锯齿、形状不符、非有限、W 负、thresholds 长度/顺序/负值或 quantiles 空、越界、递减非法抛 `ValueError`。令 `μ=H[k][i]`、`σ=W[k][i]`、`Tj=thresholds[j]`：`σ>0` 时 `qj=erfc((Tj−μ)/(σ*sqrt(2)))/2`，否则 `Tj≤μ` 取 `1.0`、否则 `0.0`；`p=[1−q0, q0−q1, q1−q2, q2]`。对每受体 `i`、等级 `l` 在状态 `(r,m)`（当前连续长度 `r`、历史最长 `m`）上递推，初态 `D[(0,0)]=1.0`；按 `k=0..K−1`、状态键字典序，`l` 事件以 `p[k][i][l]` 转 `(min(r+1,K), max(m,r+1))`，非 `l` 事件以 `1−p[k][i][l]` 转 `(0,m)`，落入同一目标状态的概率以 `math.fsum` 合并；`G[m]=fsum(D[(r,m)] for r=0..K)`。分位 `q=0` 取 `0`，否则取最小 `m` 使 `fsum(G[r] for r=0..m)>=q`。返回分位×受体×等级（`l=0..3`）序的 M×N×4 `list[list[list[int]]]`，按 quantile/受体/等级序，不舍入
  - `receptor_level_run_stats(H, W, thresholds, minimum=1)`：各受体各健康等级在逐情景序列中合格连续段（run）的统计（情景误差独立，按给定情景次序折入，每受体、每等级独立递推；长度达到 `minimum` 的连续段计为一段合格段）。`H`、`W` 为同形 K×N（K,N>0）list/tuple 矩阵，外层/行限 list/tuple 且等宽；`H` 元素为非 bool 有限 int/float（可负），`W` 元素为非 bool 有限 int/float 且 ≥0；`thresholds` 为 list/tuple，恰含 3 个严格递增非 bool 有限非负数；`minimum` 为非 bool 且 `>=1` 的 int。容器/元素类型错抛 `TypeError`；空、空行、锯齿、形状不符、非有限、W 负、thresholds 长度/顺序/负值非法或 `minimum<1` 抛 `ValueError`。令 `μ=H[k][i]`、`σ=W[k][i]`、`Tj=thresholds[j]`：`σ>0` 时 `qj=erfc((Tj−μ)/(σ*sqrt(2)))/2`，否则 `Tj≤μ` 取 `1.0`、否则 `0.0`；`p=[1−q0, q0−q1, q1−q2, q2]`。对每受体 `i`、等级 `l` 在状态 `(r,c)`（当前连续长度 `r`，截断于 `m=minimum`；已完成合格段数 `c`）上递推，初态 `D[(0,0)]=1.0`；按 `k=0..K−1`、状态键字典序，`l` 事件以 `p[k][i][l]` 转 `(min(r+1,m), c+1)`（当 `r<m` 且 `r+1==m`）或 `(min(r+1,m), c)`（否则），非 `l` 事件以 `1−p[k][i][l]` 转 `(0,c)`，落入同一目标状态的概率以 `math.fsum` 合并。`probability[i][l]=fsum(D[(r,c)] for c≥1)` 为至少一段合格段的概率，`expected_runs[i][l]=fsum(c*D[(r,c)])` 为合格段数期望。返回 `(probability, expected_runs)`，均为受体×等级序的 N×4 `list[list[float]]`，不舍入

  - `policy_recommend(H, W, thresholds, quantiles, policies, options, budget, weights=None, z=1.96)`：为每个非支配缓解方案搭配最优运行预警策略。除 `quantiles`、`policies` 外，参数约束与每种错误条件的异常类型沿用 `receptor_mitigation_frontier`；二者沿用 `receptor_count_run_policy_batch`（故 K≥2）。令 `F=receptor_mitigation_frontier(H,W,thresholds,options,budget,weights,z)`；对其中 `(choice,C,S,D,G,interval)`，构造 `H′[k][i]=H[k][i]−options[i][choice[i]][0]`，以 `H′` 代替 `H` 调用批量函数得 `(results,scores,order)`，令 `p=order[0]`、`o=results[p]`、`a=max(o[1])`、`s=scores[p]`。返回各 `(choice,p,C,S,D,G,a,s,interval,o)` 组成的 list，按 `(S,D,G,C,−a,−s,choice,p)` 升序；内部类型、形状沿既有返回，数值不舍入
  - `robust_policy_summary(H, W, thresholds, quantiles, policies, options, budget, weight_sets, z=1.96)`：在多组情景权重下稳健地挑选预算内的缓解方案与运行预警策略（仅自 `air_quality.health` 导出，不入包根）。除 `weight_sets` 外，参数约束与每种错误条件的异常类型沿用 `policy_recommend`（故 K≥2）。`weight_sets` 为非空 L×K list/tuple 矩阵，元素为非 bool 有限非负数，各行 `fsum>0` 后按 `fsum` 归一；容器/行/元素类型错抛 `TypeError`，空、锯齿、行长不等于 K、非有限、负值或行零和抛 `ValueError`。枚举每个预算内 `(choice,p)`（`choice` 为每受体各选一选项且成本 `C=fsum(c_i)≤budget`，`p` 遍历全部策略）：构造 `H′[k][i]=H[k][i]−options[i][choice[i]][0]`，对每权重行 `w` 调用 `receptor_excess_interval(H′,W,thresholds,w,z)` 得 `I=(M,R,L,U)`，按 `p` 的策略参数调用 `receptor_count_run_warning` 得 `o`。令 `S=fsum(max(U[i][j],0))`、`D=fsum(R[i][j])`、`G=Σ[L[i][j]>0]`（`i<N, j<3`）、`a=max(o[1])`、`s=fsum(o[4][K−1])`；对每一权重行，所有 `(choice,p)` 按 `(S,D,G,C,−a,−s,choice,p)` 升序赋 0 基名次，`ranks` 收齐该对的 L 个名次。取 `(max(ranks),fsum(ranks),choice,p)` 最小者，返回 `(choice,p,ranks,metrics,intervals,o)`：`choice` 为 N 长 0 基选项下标 `list[int]`，`p` 为 int，`ranks` 为 L 长 `list[int]`，`metrics` 含 L 个 `(S,D,G,C,a,s)`，`intervals` 含 L 个 `(M,R,L,U)`，`o` 沿 `receptor_count_run_warning` 既有结构，数值不舍入；无可行组合抛 `ValueError`
  - `robust_policy_report(H, W, thresholds, quantiles, policies, options, budget, weight_sets, z=1.96)`：多组情景权重下稳健方案与预警策略的 JSON 兼容摘要（仅自 `air_quality.health` 导出，不入包根）。参数约束与每种错误条件的异常类型沿用 `robust_policy_summary`，异常原样传播。仅调用 `robust_policy_summary` 一次取 `(choice,p,ranks,metrics,intervals,o)`，返回键依次为 `choice`、`policy`、`robustness`、`weights`、`warning` 的 dict：`choice` 为 `choice` 的 list 副本，`policy` 为 `p`；`robustness` 为 `[max(ranks), fsum(ranks), list(ranks)]`；`weights` 按 `weight_sets` 序，第 l 项为 `[S,D,G,C,a,s,M,R,L,U]`，前六值取 `metrics[l]`，后四值取 `intervals[l]` 并复制为二维 list；`warning` 按 `o` 中 `[runs,levels,triggers,first,cumulative]` 的顺序，所有内层容器递归转 list，`None` 保留；数值不舍入
  - `robust_policy_sensitivity(H, W, thresholds, quantiles, policies, options, budget, weight_sets, zs)`：稳健方案与预警策略对区间倍数 `z` 的敏感性扫描（仅自 `air_quality.health` 导出，不入包根）。除 `zs` 外，参数约束与每种错误条件的异常类型沿用 `robust_policy_report`，异常原样传播。`zs` 为非空 list/tuple，元素为非 bool 有限 int/float、≥0 且严格递增；容器或元素类型错抛 `TypeError`，空、非有限（含 int 转 float 溢出）、负值或非递增抛 `ValueError`。对每个 `z` 按序以其余同参仅调用一次 `robust_policy_report`，结果记 `R[r]`。将 `R` 中相同 `(choice,policy)` 分组，`S` 按首次出现序存 `[choice副本, policy, 次数]`；`D` 第 r 行为 `R[r+1]` 与 `R[r]` 的 `robustness[2]` 逐项之差，`G` 第 r 行为两者 `warning[1]` 逐项之差；仅一个 `z` 时 `D`、`G` 为空。返回键依次为 `z`、`reports`、`selection_counts`、`rank_changes`、`level_changes` 的 dict，值依次为 `zs` 转 float 的 list、`R`、`S`、`D`、`G`，均按 `zs` 及原 `weight_sets`/`quantiles` 序；全部容器 JSON 兼容，`None` 保留，数值不舍入
  - `robust_policy_grid(H, W, thresholds, quantiles, policies, options, budgets, weight_sets, zs)`：稳健方案与预警策略在预算×区间倍数网格上的扫描（仅自 `air_quality.health` 导出，不入包根）。除 `budgets`、`zs` 外，参数约束与每种错误条件的异常类型沿用 `robust_policy_report`，异常原样传播；`budgets`、`zs` 均沿用 `robust_policy_sensitivity` 的 `zs` 契约（非空 list/tuple，非 bool 有限 int/float、≥0 且严格递增；容器或元素类型错抛 `TypeError`，空、非有限含 int 转 float 溢出、负值或非递增抛 `ValueError`）。以 `budgets` 为外层、`zs` 为内层，每格 `(budget,z)` 以其余同参仅调用一次 `robust_policy_report`，结果组成 B×Z 矩阵 `R`。`stability[b]` 按 `z` 序存同 `(choice,policy)` 选择的极大连续段，每段为 `[首z, 末z, choice副本, policy]`。`rank_changes`、`level_changes` 均为键依次 `z`、`budget` 的 dict：`z` 值为 B×(Z−1) 矩阵，取 `R[b][r+1]` 与 `R[b][r]` 的 `robustness[2]`（或 `warning[1]`）逐项后减前；`budget` 值为 (B−1)×Z 矩阵，取 `R[b+1][r]` 与 `R[b][r]` 的同项差；单点轴对应维度为空。返回键依次为 `budgets`、`z`、`reports`、`stability`、`rank_changes`、`level_changes` 的 dict，前两项为 `budgets`、`zs` 转 float 的 list，`reports` 即 `R`；均按 `budgets`/`zs` 及原 `weight_sets`/`quantiles` 序，全部容器 JSON 兼容，`None` 保留，数值不舍入

  - `robust_policy_action_checkpoint(H, W, thresholds, quantiles, policies, options, budgets, weight_sets, zs, capacity=10, rank_threshold=0.0, level_threshold=0.0, cursor=0, *, target_cursor, expected_done)`：确认波次并校验此前已完成行动数（仅自 `air_quality.health` 导出，不入包根）。签名为 `robust_policy_action_confirm` 在 `target_cursor` 后增加必填仅关键字参数 `expected_done`；其余参数及逐项异常沿用 `robust_policy_action_confirm` 并原样传播。`expected_done` 为非 bool 且 ≥0 的 int，错型抛 `TypeError`，负值抛 `ValueError`。仅调用 `robust_policy_action_confirm` 一次得 `C`，令 `old`、`new`、`delta`、`remaining` 依次为 `C["summary"]` 的第 2 至 5 项（0 基，即 `old`、`new`、`new−old`、`Q−new`）；若 `expected_done != old` 抛 `RuntimeError`。返回键依次为 `budgets`、`z`、`capacity`、`checkpoint`、`confirmed`、`pending`、`hits` 的 dict：其中六项递归复制 `C` 的同名值，`checkpoint` 为键依次 `from_cursor`、`to_cursor`、`next_cursor`、`old_done`、`done`、`delta`、`remaining` 的 dict，值依次为 `C["from_cursor"]`、`C["to_cursor"]`、`C["to_cursor"]`、`old`、`new`、`delta`、`remaining`。`target_cursor==cursor` 合法，此时 `confirmed` 为空、`delta` 为 0。全部容器 JSON 兼容，`None` 保留，数值不舍入

  - `robust_policy_action_resume(checkpoints, cursor=0, expected_done=0, limit=1)`：回放检查点恢复已确认状态并按限额切出下一批行动计划（仅自 `air_quality.health` 导出，不入包根）。前三参契约与异常沿用 `robust_policy_action_restore` 并原样传播；`limit` 为 `None` 或非 bool 且 ≥1 的 int，错型抛 `TypeError`，小于 1 抛 `ValueError`。仅调用 `robust_policy_action_restore` 一次得 `S`，令 `P=S["pending"]`；`limit` 为 `None` 时 `plan` 取 `P` 全部，否则取 `P[:limit]`，`left` 取其余项，均保持顺序并递归复制。返回键依次为 `state`、`plan`、`pending`、`hits`、`history` 的 dict，值依次为 `S` 的 `state` 副本、`plan`、`left`、`S` 的 `hits` 与 `history` 副本。不修改 `checkpoints`，异常时无状态推进，同一输入重复调用结果相等；`P` 为空时 `plan` 与 `pending` 为空、`state` 不变。全部容器 JSON 兼容，`None` 保留，数值不舍入
  - `robust_policy_action_commit(checkpoints, completed, failed=False, cursor=0, expected_done=0)`：提交一次波次执行，成功项标记完成、失败项与未确认项回滚为 pending（仅自 `air_quality.health` 导出，不入包根）。`checkpoints`、`cursor`、`expected_done` 契约与异常沿用 `robust_policy_action_resume` 并原样传播；`completed` 为非 bool 且 ≥0 的 int、`failed` 为 bool，错型抛 `TypeError`，`completed` 为负抛 `ValueError`。以 `limit=max(1,completed+int(failed))` 仅调用 `robust_policy_action_resume` 一次得 `S`；请求数 `completed+int(failed)` 超过 `S["plan"]` 长度时抛 `ValueError`。`C` 复制 `S["plan"]` 前 `completed` 项并将各项状态（第 0 项）改为 `"done"`；`P` 复制 `S["plan"][completed:]+S["pending"]`，故失败项与未确认项回滚。令 `[c,d,r]=S["state"]`；`C` 为空时 `nc,nd,nr=c,d,r`，否则 `nc=C[-1][-1]`、`nd=C[-1][2]`、`nr=r-nd+d`。返回形状与 `robust_policy_action_checkpoint` 一致、键序为 `budgets`、`z`、`capacity`、`checkpoint`、`confirmed`、`pending`、`hits`：`budgets`、`z`、`capacity` 复制输入末项同名值，`confirmed=C`、`pending=P`、`hits` 复制 `S["hits"]`；内层 `checkpoint` 按既有键序 `from_cursor`、`to_cursor`、`next_cursor`、`old_done`、`done`、`delta`、`remaining` 取值 `[c,nc,nc,d,nd,nd-d,nr]`。结果可追加给 `checkpoints` 供后续 restore/resume 使用。所有列表递归复制，全部容器 JSON 兼容，`None` 保留，数值不舍入
  - `robust_policy_action_audit(checkpoints, attempts, cursor=0, expected_done=0)`：审计一串波次提交是否与记录的检查点一致（仅自 `air_quality.health` 导出，不入包根）。记 `C=checkpoints`、`A=attempts`；前三参契约与异常沿用 `robust_policy_action_restore` 并原样传播。`A` 为比 `C` 少 1 项的 list/tuple，各项为二元 list/tuple `(c,f)`，`c` 为非 bool 且 ≥0 的 int、`f` 为 bool；`A` 容器或项、`c`、`f` 类型错抛 `TypeError`，长度不符、元数不为 2 或 `c` 为负抛 `ValueError`。仅调用 `robust_policy_action_restore` 一次得 `S`；逐 i 调用 `robust_policy_action_commit(C[:i+1],c,f,cursor,expected_done)`，异常原样传播，结果与 `C[i+1]` 不等时抛 `RuntimeError`。`retry` 在 `i>0` 且 `A[i-1]` 的 `f` 为真且 `c+int(f)>0` 时为真；`history[i]=[i,c,f,retry,C[i+1]["checkpoint"]` 副本 `]`。返回键依次为 `state`、`history`、`pending`、`hits`、`summary` 的 dict：前四项中 `state`、`pending`、`hits` 复制 `S` 同名值，`summary=[A 长度,c 之和,f 真数,retry 真数,S["state"][1],S["state"][2]]`。全部容器 JSON 兼容，不修改输入
  - `robust_policy_action_audit_chain(audits)`：将多段 `robust_policy_action_audit` 结果按段序展平为一条跨段审计链（仅自 `air_quality.health` 导出，不入包根）。`audits` 为非空 list/tuple，各项须符合 `robust_policy_action_audit` 返回契约（键恰为 `state,history,pending,hits,summary`；`state` 为 3 个非 bool 且 ≥0 的 int；`history` 项为 5 元 `[号,completed,failed,retry,checkpoint]`，checkpoint 七键俱全且为非 bool 非负 int；`pending`、`hits` 为 list；`summary` 为 6 项）且内部自洽（号自 0 严格递增、checkpoint 满足 `next_cursor=to_cursor`、`delta=done−old_done`、游标不回退、同段相邻 checkpoint 衔接且满足 `remaining=前一 checkpoint 的 remaining−本 delta`、末 checkpoint 与 state 一致、段内 retry 与统计汇总一致），同段相邻 checkpoint 的 remaining 递推不符抛 `ValueError`。容器/标量类型错抛 `TypeError`；空序列、键缺失/多余、结构错或统计不符抛 `ValueError`。后段 `history` 非空时其首 checkpoint 的 `from_cursor`、`old_done` 须分别等于前段 `state` 前两项；为空时其 `state` 须等于前段 `state`，否则抛 `RuntimeError`。各段按段序展平、全局自 0 编号；全局 `retry` 指展平序列中前项 `failed` 为真且本项 `completed+int(failed)>0`，跨段边界同样适用；`retry_chains` 为相邻 retry 边的极大连通段，每段 `[首全局号,末全局号,全局号列表]`。返回键依次为 `state`、`history`、`retry_chains`、`pending`、`hits`、`summary` 的 dict：`state`、`pending`、`hits` 复制末段同名值；`history` 项为 `[全局号,段号,局部号,completed,failed,retry,checkpoint副本]`；`summary=[段数,尝试数,completed之和,失败数,retry数,末done,末remaining]`。不修改输入，全部容器 JSON 兼容，`None` 保留，数值不舍入
  - `audit_delta(previous, current)`：比较前后两次 `robust_policy_action_audit_chain` 结果（记两参为 P、C，仅自 `air_quality.health` 导出，不入包根）。P/C 须符合 `audit_chain` 返回契约（各自按单元素链逐项校验）：错型抛 `TypeError`，结构/统计/递推错抛 `ValueError`。此外 `C["history"]` 须以 `P["history"]` 为严格前缀，否则 `ValueError`；有后缀时后缀首 checkpoint 须满足 `[from_cursor,old_done,remaining]=[P["state"][0],P["state"][1],P["state"][2]−delta]`，无后缀时两 state 须相等，否则 `ValueError`。D 为 `C["summary"]` 逐项减 `P["summary"]` 的 7 项差：前 6 项须 ≥0、末项须 ≤0（否则 `RuntimeError`）；增量须与后缀一致——第 1、2、3 项分别等于后缀 `completed` 之和、真 `failed` 数、真 `retry` 数，第 0 项不小于后缀出现的不同段号数，第 5、6 项分别等于两 state 第 1、2 项之差，增量关系不符抛 `RuntimeError`。retry_chains 逐值比较（三项全等即同一条）并成对抵消。返回键依次为 `states`、`delta`、`history`、`retries` 的 dict：依次为 `[P state 副本, C state 副本]`、D、`C["history"]` 的后缀副本、`[C 特有 retry_chains, P 特有 retry_chains]`（两侧均保原序）。全部容器递归复制、JSON 兼容，不修改输入
  - `audit_reconcile(snapshots)`：沿时间序列对账多份 `robust_policy_action_audit_chain` 快照（仅自 `air_quality.health` 导出，不入包根）。`snapshots` 记为 S、为非空 list/tuple，各项须符合 `robust_policy_action_audit_chain` 返回契约；容器或项错型抛 `TypeError`，空序列抛 `ValueError`。先以 `audit_delta(S[0],S[0])` 校验首项；i=1..L−1 各调用一次 `audit_delta(S[i−1],S[i])`，异常原样传播，结果依次构成 steps（L=1 时 steps 为空）。整体 `delta` 为末、首两份 snapshot 的 7 项 summary 逐项后减前，须等于 steps 各 `delta` 逐项以 `sum` 汇总的结果，否则抛 `RuntimeError`。`retries` 初值 `[[],[]]`，依 steps 先处理新增（各 step `retries[0]`）再处理移除（各 step `retries[1]`）：当前项与反向列表首个相等项抵消（删除该反向项），否则向本向列表追加其递归副本。返回键依次为 `states`、`delta`、`steps`、`retries` 的 dict：`states` 为首项与末项 state 的副本，`steps` 为各 `audit_delta` 结果的副本。所有容器递归复制、JSON 兼容，不修改输入
  - `quantile(H, W, quantiles, weights=None, z=1.96)`：情景总健康影响的加权分位数及区间
  - `receptor_quantile(H, W, quantiles, weights=None, z=1.96)`：分受体的加权分位数及区间
  - `receptor_risk_share(H, W, thresholds, weights=None)`：分情景、分受体的超标概率与期望超额占比，返回 K×N×3 的 `(PS, ES)`
  - `receptor_risk_quantile(H, W, thresholds, quantiles, weights=None)`：分受体、分阈值的超标概率 `v(k,i,j)` 的跨情景加权分位数；对每个 `(i,j)` 将各情景按 `(v,k)` 升序排列，`r=0` 取首项，否则取累计归一权首次 `>=r` 的情景，返回分位×受体×阈值序的 M×N×3 `list[list[list[float]]]`，不舍入
  - `sensitivity(H, W, weights=None, z=1.96)`：各受体加权均值、区间半宽及各情景的均值/方差敏感性贡献。`H`、`W` 为同形 K×N 矩阵（`H` 元素可负，`W` 元素非负）；`weights` 为 `None`（取等权 `1/K`）或按 `fsum` 归一的 K 个非负权；`z` 为非负区间倍数。返回 `(M, R, C, S)`，其中
    `M[i] = fsum(w[k]*H[k][i])`、
    `R[i] = z*sqrt(V[i])`、
    `C[k][i] = w[k]*(H[k][i]-M[i])`、
    `V[i] = fsum(w[k]*((H[k][i]-M[i])**2 + W[k][i]**2))`，
    `S[k][i]` 在 `V[i]==0` 时为 `0.0`，否则为 `w[k]*W[k][i]**2/V[i]`；
    `M`、`R` 为 N 长 `list[float]`，`C`、`S` 为 K×N `list[list[float]]`，均不舍入。
